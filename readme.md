## 🚀 Running the Machine Learning Model

Follow these steps to set up the Python environment and start the Flask API that serves the machine learning model.

### 1. Create a Virtual Environment

Create an isolated Python environment to manage the project's dependencies.

```bash
python -m venv venv
```

### 2. Activate the Virtual Environment

On **Windows**, activate the virtual environment with:

```bash
venv\Scripts\activate
```

> **Note:** Once activated, your terminal prompt will usually display `(venv)`.

### 3. Install the Required Dependencies

Install all the Python libraries required to run the machine learning model and the Flask API.

```bash
pip install flask joblib numpy scikit-learn
```

### 4. Navigate to the Application Directory

Move to the directory containing the Flask application.

```bash
cd app
```

### 5. Start the Flask Server

Launch the Flask application that exposes the machine learning model through REST API endpoints.

```bash
python app.py
```
